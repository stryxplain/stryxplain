# stryXplain website (flat version — no folders)

Sab files ek hi jagah hain. Upload karte waqt 11 files select karke ek saath drag-drop karein.

Files: index.html, styles.css, app.js, config.js, portfolio-config.js, translations.js,
favicon.svg, og-image.png, robots.txt, sitemap.xml, README.md

Edit karne ki files:
- config.js            -> contact details, services, prices
- portfolio-config.js  -> portfolio projects
- translations.js      -> sab text (English + Hinglish)
- styles.css           -> colors (top par :root)

Uploaded video / thumbnail: file ko index.html ke saath hi upload karein aur
portfolio-config.js mein sirf file ka naam likhein (jaise "my-sample.mp4").

Deploy: GitHub repository -> Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.
Live hone ke baad index.html, robots.txt, sitemap.xml mein YOUR-USERNAME / YOUR-REPO ko apne asli address se badlein.
